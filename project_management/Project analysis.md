# Choices and Decisions

<span style='color: lightblue'>

## ➡️ Graphical library
</span>

We chose to use Raylib as the graphical library for this project.

However, as stated in the subject, we had to limit our use of the library to what the MLX is capable of doing. Certain actions that we could have performed simply by using the library's functions therefore had to be broken down into more precise, smaller actions compatible with the MLX.

<span style='color: lightblue'>

## ➡️ Textures
</span>

Our Pacman does not have any texture in its assets. All needed textures are generated by our program, during execution.

<span style='color: lightblue'>

## ➡️ Bonuses
</span>

The subject does not mention any bonuses, but we chose to implement a fair amount of them. That goes from extra objects to help the player during the game, to — why not, after all — full-blown bonus games. And as orobert said :  

<i>
"It's just in case they add bonus features right before we hand in the project. Might as well be prepared for it."
</i>

<span style='color: lightblue'>

## ➡️ Documentation
</span>

Although not required by the subject, we chose to write the "project management" section in English for the sake of consistency with the rest of the project.

Since the code, the README, and even the game itself are available in English, writing this part in French would not have made sense.
